# Security

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature when it is available for this repository. Do not publish credentials, API encryption keys, Wi-Fi passwords, OTA passwords, or precise network details in an issue.

## Local network security

The example firmware uses an encrypted ESPHome API connection and password-protected OTA updates. Replace every example secret before flashing. Keep the device and Home Assistant on trusted networks, and do not expose ESPHome ports directly to the internet.
