What is HA Proxy Panel?

It turns an ESP32 and a small 128x64 OLED into a Bluetooth proxy with a live climate and status display. Control content, rotation, brightness, and OLED Care from Home Assistant, then maintain it with the desktop manager or ESPHome Device Builder.

Bluetooth proxy

Extend Bluetooth coverage for nearby BLE devices.

Climate display

Choose Home Assistant temperature and humidity sources, with climate, single-value, and proxy views.

HA controls

Choose display mode, normal or 180 degree rotation, brightness, and OLED Care without reflashing.

OLED Care

Pixel shifting and a full-panel refresh reduce long-running static patterns.

Wi-Fi status

Check signal, IP, uptime, source, firmware, proxy state, and availability. A QR fallback portal handles first setup.

Update notifications

A blinking indicator and bottom-up tray announce panel and ESPHome updates without covering climate data.

01

Flash, discover, and manage every panel.

HA Proxy Panel Manager 1.6.0 is a standalone Windows app. No Python installation is required, and ESPHome 2026.7.4 is bundled.

Connect securely

Use Home Assistant OAuth with MFA or a manual token fallback. Tokens and device secrets are encrypted for your Windows account with DPAPI.

02

Flash and onboard

Detect USB devices, import a saved Windows Wi-Fi profile, download and verify the exact GitHub firmware commit, then follow the phone QR setup when needed.

03

Discover every panel

Find panels through Home Assistant and mDNS, search the LAN, or connect directly by IP. Switching devices keeps the dashboard stable and readable.

04

Control live

Change display mode, rotation, brightness, and OLED Care. Run its animation, restart a panel, inspect entities and diagnostics, or prepare new sensor sources.

05

Update safely

Install verified official firmware over Wi-Fi while preserving identity, sensor sources, display settings, encrypted or legacy API mode, and OTA configuration.

06

Transfer the matching API key securely, complete ESPHome discovery, and create protected Device Builder YAML without overwriting an unmanaged project.

03

From parts to proxy.

The Windows Manager is the easiest route. It guides the first USB flash, phone Wi-Fi setup, secure Home Assistant addition, and later updates over Wi-Fi.

  1. 1

    Download the Manager

    Download version 1.6.0, connect the ESP32 with its supplied USB cable, and open the Install page. The app detects the serial adapter and fetches the verified firmware from GitHub.

    Download for Windows
  2. 2

    Configure and flash

    Connect Home Assistant, choose saved Wi-Fi details, name the panel, select climate entities, and flash. If Wi-Fi is not ready, scan the OLED QR and use the modern phone portal.

    Follow first-time setup
  3. 3

    Add to Home Assistant and Device Builder

    The standalone Windows manager securely adds the discovered ESPHome device to Home Assistant. It can update a selected panel from GitHub and displays both project and Home Assistant ESPHome update status. Choose Add to Device Builder to create its exact maintainable YAML and namespaced secrets through protected Home Assistant ingress.

    Read the Home Assistant guide

04

Change the screen from Home Assistant.

Native display controls take effect without reflashing and persist after a restart. The Windows Manager exposes the same daily controls across every discovered panel.

  • Climate, temperature, humidity, or proxy status
  • Normal or 180 degree rotation
  • Brightness from 10 to 100 percent
  • OLED Care switch and on-demand animation
  • Reserved scrolling title row that never enters the Wi-Fi indicator area
  • Blinking update indicator and bottom-up panel, ESPHome, or combined update tray
  • Restart, test notification, IP, signal, uptime, source, firmware, and proxy diagnostics
